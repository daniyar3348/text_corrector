## 3. Критический путь и зависимости

```mermaid
flowchart LR
    A[Морфоанализатор ✅] --> B[Датасет орфо-ошибок KK]
    B --> C[Fine-tune KazRoBERTa]
    C --> D[Интеграция в TransformerModel]
    D --> E[Единый механизм:<br/>ML → морфо-валидация]
    E --> F[Этап 5: Пилот]
    F --> G[Этап 6: Обучение]
    G --> H[Этап 7: Отчётность]

    classDef done fill:#bbf7d0,stroke:#16a34a,color:#000;
    classDef crit fill:#fecaca,stroke:#dc2626,color:#000;
    classDef norm fill:#e0e7ff,stroke:#4f46e5,color:#000;
    class A done;
    class B,C,D crit;
    class E,F,G,H norm;
```

**Критический путь:** `Датасет → Fine-tune → Интеграция модели` (этап 4). Если он скользит — скользит весь проект. Пилот (этап 5) может стартовать на гибриде (морфология + словарь) **параллельно** дообучению, чтобы не блокироваться.
