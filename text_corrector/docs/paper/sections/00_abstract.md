# Turan: Detecting and Correcting Kazakh Spelling Errors, with a Focus on the "ka2ru" Cyrillic Look-Alike Phenomenon

## Abstract

A pervasive but under-studied source of Kazakh spelling errors arises when the nine Kazakh-specific Cyrillic letters (қ, ә, ң, ұ, ү, ғ, і, ө, һ) are typed as visually similar standard-Russian Cyrillic letters because writers lack or ignore the Kazakh keyboard layout. We term this look-alike substitution the "ka2ru" error class. Because the corrupted text remains Cyrillic and superficially resembles Russian, it also defeats naive language identification. We address this problem with a two-stage pipeline that separates error detection from correction. A KazRoBERTa [liu2019roberta] [kztransformers2023kazroberta] encoder is fine-tuned as a token classifier that labels each token KEEP or ERROR, following the tag-not-rewrite paradigm for grammatical error correction [omelianchuk2020gector]; flagged tokens are then resolved by a corrector that combines inverse look-alike substitutions, a frequency-weighted lexicon, restricted Damerau–Levenshtein candidate search [damerau1964technique], and morphological guarding of valid inflected forms. To train and evaluate the system, we construct a parallel corpus of 2,615,771 sentence pairs (2,565,771 training pairs) by injecting six error types into cleaned Kazakh text via confusion-set-based synthetic generation [grundkiewicz2019synthetic], with ka2ru as the dominant class (30.5% of injected edits). On a held-out test set the detector attains an F1 of 97.3% (precision 97.1%, recall 97.4%), and the full pipeline corrects 80.5% of sentences completely, approaching the oracle ceiling of 83.5% obtained under perfect detection. These results indicate that detection is essentially solved for this setting and that the corrector is the remaining bottleneck. The system runs CPU-only and was validated in an accepted live pilot.

## Keywords

Kazakh spelling correction; ka2ru look-alike errors; KazRoBERTa; token classification; synthetic error generation; language identification; agglutinative morphology
